Zee3 is one program, `zee3`, that contains the S3 API, the admin API, the replication API and the web
console. Without a command it runs a node; `zee3 admin ...` manages a running node (see the
[CLI](/cli/overview)).

## Docker image

The image runs on `linux/amd64` and `linux/arm64`.

```bash
docker pull terrificci/zee3:latest
```

| Tag | Meaning |
| --- | --- |
| `latest` | The newest release |
| `1.0.0` | One exact version |

Pin a version tag to choose when you upgrade. Continue with [Docker](/deploy/docker).

## Install script

On Linux, install the `zee3` binary with one command:

```bash
curl -fsSL https://raw.githubusercontent.com/terrific-ci/z3/main/install.sh | sh
```

The script picks the archive for the machine's CPU (amd64 or arm64)
from the latest [GitHub release](https://github.com/terrific-ci/z3/releases), checks it against the
release's `SHA256SUMS`, and puts `zee3` in `/usr/local/bin` (asking for `sudo` when it needs to). Run
it again to upgrade.

| Option | Meaning |
| --- | --- |
| `--service` | Also run Zee3 as a systemd service and start it (Linux only); see [systemd](/deploy/systemd) |
| `--version X` | Install version `X` (such as `1.0.0`) instead of the latest release |
| `--dir DIR` | Install into `DIR` instead of `/usr/local/bin` |

Pass options after `sh -s --`:

```bash
curl -fsSL https://raw.githubusercontent.com/terrific-ci/z3/main/install.sh | sh -s -- --version 1.0.0
```

The environment variables `ZEE3_VERSION` and `ZEE3_INSTALL_DIR` do the same as `--version` and
`--dir`.

<Accordion title="Without the script">
  Each release has one archive per CPU, each holding the `zee3` binary, plus a `SHA256SUMS`
  file:

  | Platform | Archive |
  | --- | --- |
  | Linux, x86-64 | `zee3-<version>-linux-amd64.tar.gz` |
  | Linux, ARM64 | `zee3-<version>-linux-arm64.tar.gz` |

  ```bash
  VERSION=1.0.0
  ASSET=zee3-$VERSION-linux-amd64.tar.gz
  curl -fLO https://github.com/terrific-ci/z3/releases/download/v$VERSION/$ASSET
  curl -fLO https://github.com/terrific-ci/z3/releases/download/v$VERSION/SHA256SUMS
  grep " $ASSET\$" SHA256SUMS | sha256sum -c -
  tar -xzf $ASSET
  sudo install -m 755 zee3 /usr/local/bin/zee3
  ```

</Accordion>

<Note>
  On macOS, run Zee3 with [Docker](/deploy/docker).
</Note>

The console is built into the binary; there is nothing else to install.

## Check that it runs

```bash
zee3 --version
zee3 --help           # every option, with its environment variable
```

Start a node in the current directory to try it (data goes to `./data`):

```bash
zee3
```

Then open `http://127.0.0.1:9001`. A new data directory starts with the **setup page**: choose the root
access key and secret key there (they are kept in `<data dir>/credentials.json`), or join Zee3 nodes
you already run. The S3 API starts once setup is done. On a remote server the console listens on
`127.0.0.1` by default: reach it through an SSH tunnel (`ssh -L 9001:127.0.0.1:9001 server`) or set
`ZEE3_ADMIN_ADDR`. See the [Quickstart](/get-started/quickstart)
for the first bucket.

For an unattended install (a script, systemd, configuration management), set the root account in the
environment instead; the setup page then never shows:

```bash
ZEE3_ACCESS_KEY=admin ZEE3_SECRET_KEY=change-me-please zee3
```
